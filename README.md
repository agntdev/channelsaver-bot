# ChannelSaver Bot

Telegram bot that downloads videos from private channels/groups (when the bot and requester are members) and re-uploads them into the chat or to the requester.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
